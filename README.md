# Подбор автозапчастей — Favorit Parts

Веб-приложение для подбора автозапчастей по артикулу через Web-сервис «Проценка»
(Favorit Parts). Два шага: сначала все производители, у которых есть деталь с таким
номером, затем аналоги и предложения складов по выбранному производителю.

Документация сервиса: <https://lk.favorit-parts.ru/static/wsprice.pdf>

## Ключ покупателя

Ключ задаётся в блоке «Настройки подключения» (хранится в `localStorage`) или через
`VITE_FAVORIT_API_KEY` в `.env` — второй способ годится только для локальной работы,
ключ из `.env` попадает в собранный бандл.

## Структура

```
src/
  api/favoritApi.js      запросы к сервису, нормализация ответа, ApiError
  store/index.js         Redux store
  store/searchSlice.js   thunk-и searchBrands / searchOffers, статусы, ошибки, ключ
  components/
    SearchForm.jsx       поле артикула и кнопка поиска
    BrandList.jsx        карточки производителей
    OffersTable.jsx      таблица аналогов и складов
    ApiSettings.jsx      ключ покупателя
    ErrorAlert.jsx       сообщение об ошибке с повтором
    Loader.jsx           индикатор загрузки
  utils/format.js        форматирование цены, остатка и даты отгрузки
  App.jsx                сценарий из двух этапов и состояния экрана
  index.css              оформление и адаптив
```

## Скрипты

| Команда           | Что делает                                  |
| ----------------- | ------------------------------------------- |
| `npm run dev`     | dev-сервер Vite с горячей перезагрузкой      |
| `npm run build`   | production-сборка в `dist/`                 |
| `npm run preview` | локальный просмотр собранной версии         |
| `npm run lint`    | проверка кода oxlint                        |

## Как устроены запросы

Один эндпоинт, метод GET:

```
http://api.favorit-parts.ru/hs/hsprice/
```

## Ограничения

- **Сервис работает только по HTTP.** Со страницы по HTTPS браузер заблокирует запросы
  (mixed content), поэтому нужен HTTPS-прокси; его адрес задаётся через `VITE_API_BASE_URL`.
- **Ключ живёт в браузере** — для публичного стенда ключ и лимит запросов должны быть
  на прокси, а не в клиенте.
